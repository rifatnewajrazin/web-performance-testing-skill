# Contributing

Thanks for helping. A few ground rules keep the kit useful.

- Keep rules short and testable. If you cannot tell whether the AI followed it, rewrite it.
- Write in plain words. No em dashes, no en dashes, no emojis in prose, no filler like "it is worth noting".
- No personal data, client names or secrets in examples. Use made-up names.
- One change per pull request, with a line on why it helps.
- If you add a rule, say what went wrong that made you add it.

Open an issue first for anything big.
